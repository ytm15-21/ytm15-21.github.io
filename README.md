# YouTube Mobile 2021/YTm21
A frontend/web-client for YouTube mobile based off the 2015 YT app for Android, modified to look like the 2021 one

## Want the desktop UI instead?
Consider checking out <a href="https://vorapis.pages.dev/#/">Vorapis 2013/V3</a> + <a href="https://github.com/lightbeam24/StarTube">StarTube</a>, another projects made by another persons in the Old YouTube community, V3 + StarTube also aims to restore YouTube's old UI, you can configure/stylize it to make it look like YouTube in 2021. <a href="https://chromewebstore.google.com/detail/customtube-restore-the-ol/iedffooliepgabiihipcbokboecnfcbe">CustomTube</a> also exists, however it's discontined/no-longer maintained
